# Girls Go Midterm Poly Markets

Daily dashboard of the most traded 2026 midterm markets on Kalshi and Polymarket.

## Setup
1. Push this repo to GitHub.
2. Settings > Pages > Deploy from branch > `main` / `/docs`.
3. Actions > Daily dashboard > Run workflow. It then runs every day at 14:00 UTC.

Change `TOP_N` at the top of `build.py` to list more or fewer markets.
